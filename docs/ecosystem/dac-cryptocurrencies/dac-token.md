# DAC Token

A fixed number of 1 Billion DACT have been generated and perform the following functions:

* serve as a collateral to users for the recognition of Supervisor and Supervisor nodes within the network. With a certain amount of DACT, a Token Holder may activate a Supervisor or a Validator node;
* regulate the distribution of new DACC (DAC Coin) as a reward for the participation to the network.

DACT have been generated in compliance with the standardized Ethereum ERC-20 tokens. This decision was made to consolidate the security of the DACT.&#x20;

DACT are hosted on Ethereum blockchain, chosen for its stability and large-scale adoption.

The DAC Tokens supply is capped at 1 Billion DACT, they cannot be minted and they have no timelock on them. All the characteristics of the DACT can be viewed on Ethereum explorer at this address: [0x0d9e0916ea60d5439f1535bea4cb83b25780eb36](https://etherscan.io/token/0x0d9e0916ea60d5439f1535bea4cb83b25780eb36)

## How to show DACT in Ethereum wallets

DAC Token have been generated in compliance with the standardized Ethereum ERC-20 tokens and can be used in any Ethereum wallet that supports this kind of cryptocurrencies.

The configuration may vary in every single application. It's important to select the _Add Token_ in your Ethereum wallet application with these settings:

|                        |                                            |
| ---------------------- | ------------------------------------------ |
| Token Contract Address | 0x0d9e0916ea60d5439f1535bea4cb83b25780eb36 |
| Name                   | DAC Token                                  |
| Token Symbol           | DACT                                       |
| Decimal of Precision   | 18                                         |
